# The tells of a generic, AI-made app

People who see many generated apps recognise these at a glance, and then stop believing the rest. Each is fine as a
deliberate choice the brief asks for; none is fine as a default. The pipeline's UI check flags the ones a machine can
see (marked ●); lorem ipsum fails it outright.

| Tell | Instead |
|---|---|
| ● An indigo, violet or pink gradient on a hero, a card or a button | The brand's tokens, flat. One accent, used for action |
| ● Gradient-filled headings | A solid colour token; let size and weight make the hierarchy |
| ● Frosted glass panels (backdrop blur on see-through surfaces) | Solid surface tokens with a clear edge |
| ● Emoji as icons ("🚀 Get started", "Welcome back 👋") | A drawn icon from the kit's icon set, or no icon |
| ● Lorem ipsum, `John Doe`, `Acme`, `user@example.com`, "Item 1" | Domain-real sample data (`use-case-brief.md`) |
| ● Buzzwords: seamless, supercharge, effortless, world-class, next-generation | What it does, in the domain's own nouns |
| A marketing hero (big headline, subtitle, two buttons) at the top of a working screen | Open on the work: the queue, the record, the figures that need attention |
| Every block in an identical rounded card with the same soft shadow | Group by spacing and alignment; a card only where an object is movable or selectable |
| Three icon-in-a-circle "feature" tiles | The actual feature, working |
| KPI cards with round numbers and a green "+12%" | The few figures the users act on, with units, periods and links to the records |
| "Welcome back, Sarah" as the page heading | The screen's name and its job ("Payments awaiting approval") |
| Centred text and centred layouts in a tool | Left-aligned text, a grid that lines things up |
| The same spacing between everything | A rhythm: tight inside a group, generous between groups |
| Every heading the same size and weight; or every word bold | A type scale with two or three steps actually used |
| A tracked-out ALL-CAPS label above every heading | Only where the label carries information |
| Pill-shaped everything, the same radius on every element | Radius that follows the kit's tokens and the element's role |
| A spinner for every load | A skeleton in the shape of what is coming; a spinner only for actions |
| A toast for every success | Inline confirmation where the change happened; toasts for background results |
| Dark mode by default for a business tool | The mode the brief asks for; light is the default for daytime office work |
| ✨ sparkles and "AI-powered" badges everywhere | Mark AI output where it appears, plainly ("Drafted by AI") |
| Stock illustrations of people high-fiving | Nothing, or the client's own imagery when the brand provides it |
