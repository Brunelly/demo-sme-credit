# Skills for coding agents

Each folder here is a skill: a `SKILL.md` an agent reads before a kind of work, plus the references and scripts
it points to. Each keeps its own licence and notice files, and a `README.md` saying where it came from; keep them
when you copy or update a skill.

| Skill | Read it before | Licence |
|---|---|---|
| [`maitento/`](maitento/SKILL.md) | touching `maitento/` (agents, interactions, tools) or calling the Maitento SDK | Apache-2.0 (`maitento/LICENSE`, `maitento/NOTICE`) |
| [`product-ui/`](product-ui/SKILL.md) | **first, before building or reshaping any screen**, and before calling UI work done: the use-case brief, the screen's archetype, enterprise credibility, the generic tells, and reviewing your own screenshots | part of this repository (`product-ui/README.md`) |
| [`frontend-design/`](frontend-design/SKILL.md) | building a new screen or reshaping an existing one | Apache-2.0 (`frontend-design/LICENSE.txt`) |
| [`impeccable/`](impeccable/SKILL.md) | any UI edit (its `reference/craft-floor.md` first), polishing or auditing a screen, and fixing a design-detector finding | Apache-2.0 (`impeccable/LICENSE`, `impeccable/NOTICE`) |
| [`hallmark/`](hallmark/SKILL.md) | any screen that shows figures, claims, customers or quotes, and before calling UI work done (the floor) | MIT (`hallmark/LICENSE`) |

The UI skills work inside `AGENTS.md`'s UI rules: screens are built from `packages/ui` and its tokens.
